# CSS语法
```html
选择器{
    属性1:属性值1;
    属性2:属性值2;
}
```
1.选择器的声明中可以写无数条属性
2.声明的每一行属性，都是以英文分号结尾；
3.声明中的所有属性和只都是以键值对这种形式出现的
```html
<!--这是一个p标签选择器*-->
p{
    color:blue;
    font-size:16px;
}
```
